
# AGENTS.md

## Stack
React, TypeScript, Vite, pnpm.


## Approval and Safety
- Before making any changes, inspect the relevant files and propose a short plan.
- List the files you intend to create, modify, or delete, and explain the purpose of each change.
- Wait for my explicit approval before editing files.
- After approval, implement only the agreed changes.
- If the scope needs to change, stop and ask for approval again.
- Never delete files, modify project configuration, install dependencies, or perform destructive operations without explicit approval.
- Before finishing, summarize the changes and show the relevant diff.


## Conventions
- Follow existing project patterns.
- Keep changes focused on the requested task.
- Reuse existing components and utilities.
- Avoid adding dependencies unless necessary.
- Don't refactor unrelated code.
- Prefer small, focused changes.
- Explain important decisions and trade-offs.

## Validation
- Run the relevant tests after changes.
- Run typecheck if available.
- Don't print entire command logs; summarize failures.

## Workflow
- Inspect relevant files before editing.
- Don't scan the entire repository unless necessary.
- Report changed files and validation results briefly.
